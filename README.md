# Пятница 2

Персональный Telegram-помощник для наблюдения за спотовым рынком, бумажных
сделок и отдельного журнала фактических ручных сделок. Доступны Binance и OKX.
Бот использует публичные рыночные данные. Для расчётов биржевой ключ не нужен.

## Запуск

1. Установите Python 3.13 и зависимости через `python -m pip install -r requirements.txt`.
2. Скопируйте `.env.example` в `.env`. Заполните `TELEGRAM_TOKEN` и числовой
   `BOT_OWNER_ID`. Команды принимаются только от владельца в личном чате.
3. Укажите нужные площадки в `SIGNAL_EXCHANGES` и ставку комиссии за одну
   сторону в `PAPER_FEE_RATE` как долю. Например, `0.002` означает 0,2%.
4. Запустите `python bot.py`. В Telegram введите `/setup 1000 300` для
   настройки условного капитала и бюджета и `/resume` для запуска поиска.
   Суммы здесь приведены для примера бумажного прогона.

| Команда | Действие |
| --- | --- |
| `/status` | Состояние сканера и котировок |
| `/stop` | Пауза новых карточек с сохранением сопровождения |
| `/watch` | Сетапы в наблюдении, допустимая цена или причина ожидания |
| `/report` | Результаты бумажного портфеля и теневых экспериментов |
| `/positions` | Открытые бумажные позиции и их ID |
| `/close_paper ID` | Бумажное закрытие по свежей цене продажи |
| `/manual_open БИРЖА ПАРА ОБЪЁМ ЦЕНА КОМИССИЯ_USDT` | Записать фактическую покупку |
| `/manual_close ID ОБЪЁМ ЦЕНА КОМИССИЯ_USDT` | Записать фактическую частичную или полную продажу |
| `/manual` | Ручные позиции и реализованный результат |

В `/report` за последние 24 часа отдельно видны кандидаты, входы с
подходящей котировкой, доставленные карточки и подтверждённые покупки.
Медиана задержки считается от первой зафиксированной подходящей котировки
до отправки карточки. Чистый результат за окно включает все исполнения
позиций, которые закрылись за эти 24 часа, включая комиссии. Он показан
отдельно от общей просадки портфеля. Перед отправкой карточки проверяется
текущий лимит капитала и риска, а при подтверждении журнал проверяет его
повторно в транзакции.

Для бумаги используются лучшие цены и доступные количества в стакане.
Если свежих данных или объёма нет, позиция ждёт подходящую котировку.
Пересечение стопа моделируется по наблюдаемому bid. Издержки учитываются
на обеих сторонах. Модель исполнения не восстанавливает неизвестные
внутрисвечные цены и очередь заявок. Просадка рассчитана по сохранённым
наблюдениям капитала.

Откат и пробой показываются в наблюдении как экспериментальные стратегии.
`EXPERIMENTAL_SIGNALS=1` включает их карточки. По умолчанию отдельные карточки
выдаёт базовая стратегия.

## Теневой ИИ и хранение

Для включения ИИ задайте `TRADE_REVIEW_ENABLED=1`, `TRADE_REVIEW_MODEL`,
`TRADE_REVIEW_KEY` и полный HTTPS `TRADE_REVIEW_URL` совместимого провайдера
Chat Completions с JSON mode. Во внешний запрос попадают данные кандидатов
и параметры открытых позиций теневого бумажного портфеля. Оценка ИИ сохраняется вместе с задержкой.
Telegram продолжает получать сигналы по правилам при недоступной модели.
В отчёте представлены независимые бумажные портфели базового отбора, более
строгого фильтра, ИИ, отката и пробоя. У строгого варианта фиксированные
правила отбора. Дневной лимит реализованных потерь считается по UTC.
Сравнивайте число закрытых позиций, P&L и просадку за сопоставимый период.

Храните `PAPER_DB` и соседние базы экспериментов на постоянном диске приложения.
При старте бот архивирует старый `portfolio.json` в SQLite без изменения
исходника. Старые открытые записи без надёжной площадки надо сверить вручную.
После перезапуска действующие бумажные позиции сопровождаются автоматически.
Запуск поиска требуется подтвердить через `/resume`.

Пример согласованной резервной копии главной базы:

```python
from paper_ledger import PaperLedger

PaperLedger("data/paper.sqlite3").backup("data/paper-backup.sqlite3")
```

Для диагностики и принципов защитной проверки см. [инженерные образцы](docs/references.md).

Для прежних автономных модулей анализа и графиков доступен отдельный набор
зависимостей в `requirements-legacy.txt`.
