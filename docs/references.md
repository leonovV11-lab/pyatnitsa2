# Инженерные образцы

- [codex-lsp](https://github.com/code-yeongyu/codex-lsp/tree/55836641be9b7dbf85772474a21b7a5a8ebeed35).
  Используем Python LSP через `.codex/lsp-client.json`. Если MCP-инструмент
  недоступен в сессии, ту же диагностику выполняет CLI `pyright`.
  CI запускает анализ, компиляцию и сценарные тесты.
- [Cloudflare security-audit-skill](https://github.com/cloudflare/security-audit-skill/tree/c1c8a8c1471069fb0e188eeaff69b8e8db6564a8).
  Используем выборочную проверку по исходникам: граница доверия,
  наблюдаемый эффект, проверяемая правка и отдельно факты, требующие
  подтверждения на развёрнутой системе.

Репозитории используются как образцы и не входят в зависимости бота.
В текущей доработке проверяются команды владельца, свежесть котировок,
идемпотентность исполнения, сохранность журнала и сбои внешней модели.
Отдельно проверяются развёртывание, настройки секретов и хранение данных
на целевом сервере.
